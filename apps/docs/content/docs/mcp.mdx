title: MCP onboarding
description: Connect an agent over MCP with human-approved OAuth

AgentCaller exposes a remote MCP endpoint at `/mcp`. The six tools cover
setup, billing readiness, quotes, scheduling, call status and usage.
[Saved-card billing](/billing) uses separate human spending consent and monthly
Stripe invoices. Paid calling is not yet available.

## Tools

| Tool                 | Operation       | Input                                                                 |
| -------------------- | --------------- | --------------------------------------------------------------------- |
| `setup_billing`      | `billing:setup` | `idempotencyKey`; optional `setupRequestId` to poll an existing setup |
| `get_billing_status` | `billing:read`  | none                                                                  |
| `quote_call`         | `calls:create`  | A `connect_me` call with integer `maxAmountCents` (1–50,000)          |
| `schedule_call`      | `calls:create`  | The quoted call plus `quoteVersion` and `idempotencyKey`              |
| `get_call_status`    | `calls:read`    | `callId`                                                              |
| `get_usage`          | `billing:read`  | optional `before` cursor (ISO timestamp)                              |

The call inputs are the same as the [saved-card API](/billing#agent-api).
Only `connect_me` calls are accepted, and amounts are integer USD cents.
Tools return JSON text and the same object as `structuredContent`. Errors set
`isError` and return `{ "error": "..." }`.

When billing is not set up, `schedule_call` returns
`error: "billing_setup_required"` with a `setupUrl`. Ask the human to open the
link, then retry the unchanged call with the same `idempotencyKey`.

## Connect

| Setting           | Value                                                             |
| ----------------- | ----------------------------------------------------------------- |
| Endpoint          | `https://agentcaller.io/mcp`                                      |
| Resource metadata | `https://agentcaller.io/.well-known/oauth-protected-resource/mcp` |
| Transport         | Stateless Streamable HTTP, `POST` only, JSON responses, no SSE    |
| Protocol versions | 2026-07-28 and the 2025 versions                                  |
| Request body      | At most 64 KB                                                     |

Authorize with OAuth authorization code and PKCE against the issuer named in the
resource metadata. Redirect URIs must be HTTPS or loopback HTTP, so clients that
register a custom scheme such as `cursor://` cannot connect. Access tokens must
target the exact `https://agentcaller.io/mcp` audience. The endpoint and its
metadata return `503` while MCP onboarding is unavailable.

## Human connection flow

An eligible user signs in with GitHub and approves tool access. No API key or
pre-created account is needed. Disabled accounts stay disabled, and an email or
integration name cannot claim an existing account.

Tool consent always grants all four operations (`billing:setup`,
`billing:read`, `calls:create` and `calls:read`); a subset cannot be chosen. Spending approval and saved-card
setup are separate requirements. OAuth approval cannot authorize a paid call.
The host can refresh credentials or reconnect without creating another connection.
Delegated OAuth tokens cannot authorize human portal settings or consent actions.

The human can disconnect an integration under **Settings → Connected
integrations**. Subsequent requests are denied even while a token remains valid.
Disconnecting also revokes the issuer grant and its refresh tokens. Refresh and
repeated issuer consent cannot restore a revoked connection. Spending can be
revoked separately under **Settings → Billing**. Disconnecting cancels the open calls billed through that
integration. Revoking spending cancels all open saved-card calls.
